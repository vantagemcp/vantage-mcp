# Security

If you find a security issue in Vantage, please email **support@vantagemcp.dev**
with details. We'll acknowledge within a few days and keep you posted as we
work on a fix.

Please don't open a public GitHub issue for anything that could be exploited
before a fix ships.

There's no bug bounty program at this stage - this is a small, early-stage
project - but real reports are genuinely appreciated and will be credited if
you'd like.
